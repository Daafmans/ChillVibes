# ChillVibes

## Play

**[Play ChillVibes in your browser](https://daafmans.github.io/ChillVibes/game/index.html)**

The game is served straight from [`game/index.html`](game/index.html) via GitHub Pages.

To run it locally, open `game/index.html` in a browser.

## Repository layout

- `game/` – the browser game (entry point: `index.html`)
- `docs/` – design documents
- `tools/` – development tools (e.g. `uitest.html`)

## Enabling GitHub Pages

In the repo on GitHub: **Settings → Pages → Build and deployment**, set the source to **Deploy from a branch**, branch `main`, folder `/ (root)`.
